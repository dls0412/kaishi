# 开视

开视是一个本地 AI 创作画布，可以把文字、图片、视频和音频放在画布上，通过节点和连线组织素材，并使用自己配置的模型生成内容。

## Windows 使用

从本仓库 Releases 下载 Windows 免安装压缩包，解压后打开文件夹中的 `开视.exe`。请保留解压目录里的全部文件。

首次使用时，在「模型配置」中填写自己的服务地址和 API Key，并添加需要的模型。模型服务可能会收取费用，具体能力、费用和限制以所选服务商为准。开视本身不附带 API Key 或模型权重。

项目与素材保存在本机。建议定期从客户端导出项目备份，避免更换电脑或清理本地数据后丢失内容。

## 功能

- 无限画布：创建、移动和连接文字、图片、视频、音频节点，使用 `@` 或连线引用素材。
- 图片和视频生成：配置自己的服务和模型，选择比例、时长等参数，结果显示在生成节点内。
- AI 助手：通过文本模型或本机 Codex 账号对话，结合技能编写内容并生成可审核的画布操作方案。
- 本地项目与素材管理、项目导入导出、桌面客户端。
- 对支持任务查询且已获取任务编号的服务，重开后可续查远端生成结果。

助手目前可以读取画布信息、图片和视频时长；它不能完整理解视频的连续画面和声音。多个生成任务有前后依赖时，需要等待前一步完成后再继续。

## 源码运行

需要 Node.js 22 或更高版本：

```bash
npm ci
npm run build
npm start
```

在浏览器打开 `http://127.0.0.1:5173/`。开发模式使用 `npm run dev`。

在 Windows 上执行 `npm run desktop:pack` 可以打包桌面版，生成目录位于 `release/win-unpacked`。构建脚本使用当前运行的 Node.js 作为客户端本地服务运行时。

## 验证

`npm run build` 检查类型并构建；`npm run e2e:assistant` 和 `npm run e2e:recovery` 分别检查助手上下文和异步任务恢复。这些测试使用本机模拟服务，不需要真实 API Key。浏览器测试默认使用 Windows 上的 Chrome。
